PLAN FOR THE UNEXPECTED

A way back

Account access can change. Your recovery plan shouldn’t depend on it.

!
A Telegram ban cannot be prevented or reversed by this app.

Recovery requires a surviving encrypted copy and your master key. A second folder on the same disk does not protect against disk loss.

Your three locations

  1. Device originals

    The companion reads files and never removes them.

  2. Your server + recovery target

    Encrypted files stay on the server and a configured recovery mount. Use a separate disk, NAS, or independently backed-up volume.

  3. Telegram Saved Messages

    An additional encrypted copy. Losing this account does not remove the copies above.

If Telegram becomes unavailable

Sign in here and download your files from the server or recovery target.

If your server also fails

Use the encrypted .av files from the recovery target and your offline master key with the recovery command in the guide. No Telegram account or server database is required.

Keep the master key separately

A lost key cannot be reset to decrypt existing files. Keep an offline copy in a secure place and test a restore before relying on this vault.

YOU HOLD THE CONTROLS

Security

Manage access to your personal vault.

Active sessions

Android access expires after 30 days; browser sessions after 8 hours.

Protection built in

  • Password + authenticator login
  • Encrypted files and filenames at rest
  • Encrypted Telegram session at rest
  • HTTPS required for remote access
  • Authenticated integrity checks on recovery
Know the trust boundary

The server decrypts files for downloads. This version is not end-to-end encrypted against the server operator. Use a server you control.

This beta has not undergone an independent security audit. Account recovery is available to the server administrator through the local CLI.
